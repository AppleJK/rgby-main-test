# RGBY — главная (standalone)

Состав папки:
- `index.html` — вся страница одним файлом (стили, скрипты, шрифты, картинки внутри)
- `showreel.mp4` — положить сюда самостоятельно, рядом с index.html

Если `showreel.mp4` нет, блок шоурила берёт ролик с Kinescope.

## Публикация на GitHub Pages
1. Создать публичный репозиторий, например `rgby-main`.
2. Положить в корень `index.html` и `showreel.mp4` (до 100 МБ на файл).
3. Settings → Pages → Source: Deploy from a branch → Branch: main / root → Save.
4. Через 1–2 минуты страница доступна: `https://<логин>.github.io/rgby-main/`
