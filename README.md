# RGBY · сборка сайта (релиз 2026-10-14.5)

Эту папку целиком кладут и на GitHub (стенд), и на сервер. Файлы одни и те же, ничего не пересобирается.

## Что внутри
| Адрес | Что | Модуль |
|---|---|---|
| `/` (`index.html`) | Главная | main |
| `/tv/` | ТВ/Медиа | tv |
| `/policy/` `/cookies/` `/consent/` | Юридические страницы | legal |
| `/admin/news/` | CMS новостей (на сервере — за паролем) | admin |
| `/tv/?admin` | CMS кейсов поверх страницы ТВ/Медиа | tv |
| `/core/2026-10-14/` | Код и стили этой версии: React (prod), собранные скрипты, шрифты. **Не меняется никогда** — правки кода дают новую папку `core/<дата>/` | core |
| `/content/` | Базы кейсов, новостей, клиентов | content |
| `/assets/` | Картинки и логотипы (только добавляются) | assets |
| `/showreel.mp4` | Шоурил — **положить вручную** (в сборку не входит из-за веса) | media |
| `release.json` | Номер релиза и версии модулей | root |

Отличия от прототипа: скрипты собраны заранее (нет Babel в браузере), React в продакшн-версии и лежит на нашем сервере (не с unpkg), переключатели вариантов и твики скрыты, ссылки ведут на `/`, `/tv/`, `/policy/`…  
Работает и в корне домена, и в подпапке (GitHub Pages `/rgby-main-test/`): все пути относительные.

На время проверки: `robots.txt` закрывает сайт от поиска, у страниц `noindex`. Перед открытием для всех — убрать (это отдельный маленький патч модуля root + страниц).

## Первая выкладка на GitHub (стенд)
Репозиторий: https://github.com/AppleJK/rgby-main-test — старый стенд (папка `ui_kits/…`) заменяется целиком.
```
cd ~/Downloads
git clone https://github.com/AppleJK/rgby-main-test.git rgby-site
cd rgby-site
git rm -rq .
cp -R ~/Downloads/site/. .
cp ~/путь/к/showreel.mp4 ./showreel.mp4
ls -a | grep nojekyll          # должен быть .nojekyll — без него GitHub не отдаст часть файлов
git add -A
git commit -m "Релиз 2026-10-14.5"
git push
```
Settings → Pages → Deploy from a branch → `main`, `/ (root)`. Адрес: https://applejk.github.io/rgby-main-test/

На стенде форма брифа письма не отправляет (на GitHub нет сервера) — только изображает отправку. Отправка проверяется на сервере.

Дальше — по процессу в `release/RELEASE-FLOW.md` (патчи, версии, откаты).
